# Notas dos Estudantes

## Tecnologias Utilizadas

- **.NET 10.0**
- **C#**

## Pré-requisitos

Para rodar este projeto na sua máquina, você precisará ter instalado:

1. **.NET 10.0 SDK** (Para compilar e rodar o projeto)

## Como Rodar o Projeto

1. Abra um terminal.
2. Navegue até a pasta do projeto:
   ```bash
   cd 2-StudentGrades
   ```
3. Para compilar e executar o código, rode o comando:
   ```bash
   dotnet run
   ```
