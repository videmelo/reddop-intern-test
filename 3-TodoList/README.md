# Sistema de Lista de Tarefas (Todo List)

## Tecnologias Utilizadas

### Frontend
- **Angular 18**
- **TypeScript**
- **Bootstrap 5**

## Pré-requisitos

Para rodar este projeto na sua máquina, você precisará ter instalado:

1. **NodeJS e NPM** (Para gerenciar pacotes do Frontend)
2. **Angular CLI** (Interface de linha de comando do Angular). Para instalar, rode no terminal:
   ```bash
   npm install -g @angular/cli
   ```

## Como Rodar o Projeto

1. Abra um terminal.
2. Navegue até a pasta do projeto:
   ```bash
   cd 3-TodoList
   ```
3. Instale as dependências do projeto:
   ```bash
   npm install
   ```
4. Inicie o servidor de desenvolvimento do Angular:
   ```bash
   ng serve
   ```
5. Abra o seu navegador e acesse a aplicação web no endereço:
   ```
   http://localhost:4200
   ```
